# Plataforma de Gestión Humana y Territorio (Estilo UPAE Warm) 2026–2027

Esta versión integra **todas las funcionalidades** previas junto con la vista **Territorio -> Items de SSEE** inspirada en la plataforma de referencia UPAE.

## 📁 Archivos Incluidos
- `index.html`: Plataforma web unificada (Dashboard, Mapa Territorio con Leaflet.js, Análisis, Seguimiento y ETL).
- `BASE_DATOS .csv`: Conjunto de datos original.
- `empleados_compañia_limpio.csv`: Archivo de datos procesado.
- `tarea_academica_2pt1.py`: Script de Python con el pipeline ETL.

## 🚀 Despliegue en GitHub Pages
1. Descarga y extrae este archivo ZIP.
2. Sube todos los archivos a la raíz de tu repositorio en GitHub.
3. Activa GitHub Pages en `Settings > Pages` eligiendo la rama `main` / `root`.
