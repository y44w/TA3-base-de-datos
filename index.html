Flujo de Procesamiento de Datos (ETL)

Ejecutado con Python & Pandas (`tarea_academica_2pt1.py`)

# 1. Carga y verificación inicial de la Base de Datos

df_compania = pd.read_csv('BASE_DATOS .csv')

# 2. Eliminación de Duplicados y Limpieza de Nulos

df_compania = df_compania.drop_duplicates()

df_compania = df_compania.dropna(subset=['codigo_empleado', 'nombre_completo', 'departamento', 'salario', 'fecha_ingreso'])

# 3. Conversión de Tipos de Datos (String y Datetime)

df_compania['fecha_ingreso'] = pd.to_datetime(df_compania['fecha_ingreso'], format='%d/%m/%Y')

# 4. Exportación del Archivo Limpio

df_compania.to_csv('empleados_compañia_limpio.csv', index=False)
